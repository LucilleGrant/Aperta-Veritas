# Changelog

All notable conceptual, semantic, structural, and implementation changes are recorded here.

## 0.3.1-draft, 2026-09-19

### Truth and support

- Applied Recursive Truth Exposure to the framework's own definition of truth.
- Removed the formulation that defined truth as the most accurate conclusion currently available.
- Removed "singular truth" as a required inaccessible epistemic target.
- Defined truth as **what is true**.
- Distinguished truth from conclusions presently supported as true.
- Defined RTE as identifying conclusions presently best supported as true under represented observations, relations, methods, measurements, and conditions.
- Established that RTE cannot certify that its presently best-supported conclusion is identical with definitive truth.
- Exposed the compression:

```text
best supported as true
→ truth
